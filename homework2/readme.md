# Homework 2: Library Management System

## Опис завдання
Цей проект реалізує систему управління бібліотекою, яка дозволяє працювати з книгами та журналами. Основні функції включають:
- Додавання книг та журналів до бібліотеки.
- Видалення книг із бібліотеки.
- Пошук книг за автором.
- Збереження та завантаження списку книг у файл за допомогою контекстного менеджера.
- Логування дій при додаванні книг.

## Структура проекту
    homework2/ 
        ├── init.py 
        ├── decorators.py # Декоратори для логування та перевірки існування книги. 
        ├── library.py # Основна логіка бібліотеки, книги та журналів. 
        ├── library.log # Лог-файл для запису дій. 
        ├── readme.md # Інструкція до проекту. 
        ├── test_library.json # Тестовий JSON-файл для збереження книг. 
        ├── tests.py # Тестовий модуль для перевірки функціональності.

## Основні класи та функції
### Класи
- **`BookModel`**: Модель книги з атрибутами `title`, `author`, `year`.
- **`Publication`**: Абстрактний клас для публікацій.
- **`Book`**: Клас книги, що наслідується від `Publication`.
- **`Magazine`**: Клас журналу, що наслідується від `Book`.
- **`Library`**: Клас бібліотеки, що дозволяє додавати, видаляти та шукати книги.
- **`LibraryContextManager`**: Контекстний менеджер для збереження та завантаження книг у файл.

### Декоратори
- **`log_action`**: Логування дій при додаванні книг.
- **`check_exists`**: Перевірка наявності книги перед видаленням.

## Приклад використання
```python
    from homework2.library import Library, Book, BookModel

    # Створення бібліотеки
    library = Library()

    # Додавання книги
    book = Book(BookModel(title="Назва книги", author="Автор книги", year=2023))
    library.add_book(book)

    # Пошук книг за автором
    books_by_author = list(library.books_by_author("Автор книги"))
    print(books_by_author)

    # Видалення книги
    library.remove_book("Назва книги")
```
## Тестування
Для перевірки функціональності проекту використовуйте модуль tests.py. Він містить тести для:

    Видалення книг.
    Пошуку книг за автором.
    Збереження та завантаження книг у файл.
