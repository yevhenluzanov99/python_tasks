# Python Course Homeworks

Welcome to the Python Course Homeworks repository! This project contains assignments and exercises designed to help you practice and improve your Python programming skills.

## Table of Contents

- [Overview](#overview)
- [Structure](#structure)
- [Getting Started](#getting-started)
- [Contributing](#contributing)

## Overview

This repository is a collection of homework assignments for a Python course. Each assignment focuses on specific Python concepts, ranging from basic syntax to advanced topics like object-oriented programming, file handling, and more.

## Structure

The repository is organized as follows:

```
python_homework/
│
├── homework_1/
│   ├── README.md
│   ├── task_1.py
│   └── task_2.py
│
└── README.md
```

Each homework folder contains:
- A `README.md` file with instructions for the tasks.
- Python scripts for individual tasks.

## Getting Started

1. Clone the repository:
    ```bash
    git clone https://github.com/yevhenluzanov99/python_tasks.git
    ```
2. Navigate to the desired homework folder.
3. Follow the instructions in the `README.md` file for that homework.
